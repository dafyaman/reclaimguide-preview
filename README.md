# ReclaimGuide

ReclaimGuide is an early validation project for a Windows utility that would explain what is using disk space, identify lower-risk cleanup options, and keep every change behind explicit approval.

- [All Windows storage resources](https://dafyaman.github.io/reclaimguide-preview/windows-storage-resources.html)

## Share feedback

The current validation question is whether a one-time **$19.99** utility would be useful for this problem.

[Share 30-second feedback](https://docs.google.com/forms/d/e/1FAIpQLSdKrVo85XaOiukX-vTF9yFcdGb92oEZhBRwqqOPdLT9HSV5vg/viewform)

The form has two required questions about the storage problem and proposed price. Email is optional and is requested only if you want early-access updates. No Google account, payment, or download is required.

## Privacy and repository scope

- The public preview uses no analytics, advertising pixels, payment processors, or first-party cookies.
- The cleanup planner does not scan files, upload estimates, or store entries.
- [Privacy details](https://dafyaman.github.io/reclaimguide-preview/privacy.html)
- Product source and binaries are not published in this repository.

This repository contains only the public validation site and its tests. ReclaimGuide is not currently offered for sale.
