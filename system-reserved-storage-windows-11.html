What “System & reserved” means

Windows Storage settings divide usage into categories including Installed apps, Temporary files, and System & reserved.[1] The System & reserved total is a collection of operating-system needs—not a single folder and not a promise that the whole amount can be reclaimed.

There is no universal “correct” number. The total depends on the PC, its memory, enabled recovery features, update state, and Windows configuration. Compare the subcategories on your machine instead of following an arbitrary target from another PC.

Inspect the breakdown first

Start > Settings > System > Storage > Show more categories > System & reserved
  1. Record the total free space on C:.
  2. Record the amount shown for each System & reserved subcategory.
  3. Identify which subcategory is unusually large or recently changed.
  4. Change one supported setting at a time, then recheck the numbers.

Windows describes reserved storage as space used by temporary files, caches, updates, and other files. When the device is low on space, Windows can clear reserved storage for other processes such as an update.[1]

Understand the major parts

System files

Core Windows components and files required to operate, service, and update the installation. A displayed total is not a safe manual-deletion list.

Reserved storage

Working space Windows can use for temporary files, caches, and updates. Windows manages it as system conditions change.[1]

Virtual memory

The page file supports Windows memory management. Its size can differ between PCs; do not delete or disable it as a generic cleanup shortcut.

Hibernation file

Storage associated with hibernation-related features. Windows Update may temporarily disable hiberfile.sys and pagefile.sys when applying a feature update, then re-enable them afterward.[4]

System Protection

Restore points preserve snapshots of system files, applications, Registry data, and settings. Windows lets you configure its maximum disk-space allowance.[2]

Component store

WinSxS supports Windows servicing, updates, and rollback. Windows has built-in cleanup mechanisms; do not estimate safely reclaimable space by selecting and deleting files.

A safe review order

  1. Use Cleanup recommendations first. Review Temporary files, large or unused files, cloud-synced files, and unused apps through Windows Settings.
  2. Finish or troubleshoot a pending update. Update staging can temporarily change space requirements. Windows can offer an external-storage path when internal space is insufficient.[4]
  3. Review System Protection deliberately. If its subcategory is large, open System Protection and inspect its configured maximum. Reducing it also reduces recovery history; keep enough protection for your needs.[2]
  4. Let Windows manage the component store. Windows automatically reduces WinSxS over time and provides supported component-cleanup mechanisms.[3]
  5. Recheck after each step. Stop when the PC has enough free space; do not chase a smaller system number for its own sake.

What to avoid

Never delete WinSxS manually. Microsoft warns that deleting files from WinSxS can severely damage Windows, prevent the PC from booting, and make updates impossible.[3]
  • Do not delete pagefile.sys or hiberfile.sys from File Explorer.
  • Do not manually remove files from Windows, Program Files, ProgramData, recovery partitions, or unfamiliar application-data folders.
  • Do not use irreversible component-store commands copied from forums without understanding the rollback consequences.
  • Do not disable recovery features solely to match another computer’s storage total.

Common questions

Why is System & reserved so large?

The category combines multiple subcategories. Open its breakdown to determine whether the space is primarily system files, virtual memory, hibernation, restore points, or reserved storage before choosing a response.

Can I delete System & reserved storage?

Not as one category. Use Windows’ supported controls for the specific subcategory. Manual deletion can remove files required for booting, servicing, recovery, or updates.

Can I delete WinSxS?

No. Use Windows’ built-in component cleanup behavior. Microsoft explicitly warns against manually deleting WinSxS content.[3]
